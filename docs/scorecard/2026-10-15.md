# Scorecard 2026-10-15 (core cases, GPT-OSS 120B at Cerebras)

The first run of faster answers (decision 2026-10-15 "Faster answers from Cerebras"): the everyday (core) cases once each, with `model=gpt-oss-120b` on the Scorecard workflow (`suite=core`, `repeat=1`), the runner paced for the trial's five calls a minute. Level 2 not run (no AI credit yet). Compared with GLM 4.7 Flash's core runs (2026-10-13 and 2026-10-14).

¹ One run, 2026-10-14: core right answers from that run; its median, slowest and token figures are over all 54 cases (core and hard), the only timing that run recorded. The 2026-10-13 core-only run (17/20 after thinking off) had a median of 3.6 s and a slowest of 64.7 s.

42% of Cerebras's input came from its prompt cache (GLM: 0%).

**What Cerebras got wrong (first run; one run each, so partly luck):**

- `remind-hinglish`: 7:30 pm instead of the 7:00 pm asked for (half an hour off; why isn't clear from one run).
- `event`: "Saturday" became the 19th; Saturday was the 17th (weekday arithmetic).
- `three-at-once`: added two of three reminders.
- `find-note`: searched "sound system" and the index had nothing yet; it answered honestly instead of looking in the list. The same case passes on GLM, which reads the Notes list directly.
- `handover-card`: made a spending-by-category query card itself instead of handing over to setups. A fair answer, but not what the case expects.

**Verdict for now:** much faster (median 1.2 s vs ~3 s, and never the 30–60 s outliers), a little less right (15 vs 18 of 20), with a wrong time and a wrong date among the misses. Keep it for owners and admins on the trial; before anyone else gets it, try `reasoning_effort: medium` on the time and date cases and run the hard suite.
