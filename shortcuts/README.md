# Siri Shortcuts

One file per shortcut documenting its steps, the API calls it makes, and the token scopes it needs. **Never commit tokens.**

Helpers: `GA · Config` (API URL + token), `GA · API Request` (all calls go through it).
User-facing (T09): Next gig, Gigs this week, Record payment, Add gig, Who owes me. Writes always have a confirm step.
